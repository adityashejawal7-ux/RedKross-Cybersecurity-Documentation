## 5. Python Hashlib Documentation

**Resource:** Python hashlib Library

**Purpose:** Understanding cryptographic hash functions and how file content can be represented by a hash digest.

**Link:** https://docs.python.org/3/library/hashlib.html

**Relevant Topics:**

* Hash algorithms.
* SHA-256 hashing.
* Processing data to calculate a digest.
* Comparing file integrity reference values.

**Security Note:** A matching hash supports a conclusion that the compared contents match under the selected algorithm. It does not prove that a file is safe or trustworthy.

## 8. Safe and Ethical Security Practices

All cybersecurity learning, research, and testing associated with this project must be performed on systems owned by the researcher or within an explicitly authorized environment.

Potentially risky security testing should take place in an isolated lab where appropriate. Passwords, API keys, tokens, private keys, and confidential information must not be included in public repositories.

The references listed here support documentation and learning. They do not grant permission to test third-party systems.
